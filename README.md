# Marketing Mix Analysis

Exploratory data analysis project developed in Python as part of the Master in Data Science, Analytics and AI Agents by start2impact.

## Project Description

The project analyzes a marketing mix dataset containing weekly impressions from different marketing channels and related sales.

The goal is to explore the relationship between marketing impressions and sales, identify possible patterns, outliers and seasonal trends, and propose a possible marketing-mix strategy.

## Repository Structure

- `LucaRotundoReal.ipynb`: Jupyter Notebook containing the full analysis
- `data/Sample Media Spend Data.csv`: dataset used for the analysis
- `README.md`: project overview and instructions

## Dataset

The dataset includes weekly data related to:

- Google Search Impressions
- Facebook Impressions
- Email Impressions
- YouTube Paid Views
- YouTube Organic Views
- Affiliate Impressions
- Overall Views
- Sales

## Tools Used

- Python
- pandas
- numpy
- seaborn
- matplotlib
- plotly

## How to Run

Open the notebook with Jupyter Notebook, JupyterLab or Google Colab.
Then run the notebook cells in order.

## Notes

This project is based on exploratory data analysis.
The results should be interpreted as associations and observed patterns, not as causal evidence.
